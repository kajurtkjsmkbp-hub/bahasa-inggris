# 🌟 Khanza.NET English Junior - LMS Bahasa Inggris Kelas IV SD

Website Media Belajar Interaktif Bahasa Inggris untuk Siswa-Siswi **Kelas IV Sekolah Dasar (SD)**. Didesain khusus dengan visual menarik, penuh warna, ramah anak, dan dilengkapi teknologi suara (*Native Audio Speech Synthesis*) tanpa perlu instalasi server atau dependensi rumit.

---

## 📚 10 Unit Modul Lengkap (Kurikulum Merdeka - 100 Kosakata & Contoh Kalimat):

1. **Unit 1**: *What Are You Doing?* (Aktivitas Sehari-hari / Verbs: *Reading a book, Writing a letter, Studying English, Playing football, Swimming, Cooking, Sleeping, Drinking water, Riding a bicycle, Singing a song*)
2. **Unit 2**: *Things in the Classroom* (Benda & Alat Tulis di Ruang Kelas: *Whiteboard, Pencil case, Sharpener, Eraser, Ruler, School bag, Scissors, Globe, Notebook, Crayon*)
3. **Unit 3**: *Numbers & Counting* (Angka 20 - 100 & Berhitung: *Twenty, Thirty, Forty, Fifty, Sixty, Seventy, Eighty, Ninety, One hundred, Plus and Minus*)
4. **Unit 4**: *Rooms in My House* (Ruangan Rumah & Preposisi: *Living room, Bedroom, Bathroom, Kitchen, Dining room, Garage, Garden, Beside, Behind, Between*)
5. **Unit 5**: *Cooking & Cleaning* (Peralatan & Kegiatan Rumah: *Spoon, Fork, Plate, Glass, Bowl, Broom, Sweeping the floor, Washing dishes, Watering plants, Watching television*)
6. **Unit 6**: *Delicious Food & Drinks* (Makanan & Minuman Favorit: *Fried rice, Fried chicken, Noodles, Pancake, Iced tea, Orange juice, Milk, Apple, Banana, Sweet and Salty*)
7. **Unit 7**: *Cute Animals & Adjectives* (Hewan & Ciri Sifat: *Elephant, Giraffe, Rabbit, Monkey, Tiger, Butterfly, Cat, Fish, Duck, Horse*)
8. **Unit 8**: *What Time is It?* (Jam & Waktu Sehari-hari: *Seven o'clock, Half past six, Wake up, Go to school, Take a bath, Do homework, Morning, Afternoon, Night, Go to bed*)
9. **Unit 9**: *Clothes & Colors* (Pakaian & Warna-warni: *School uniform, T-shirt, Shoes, Socks, Hat, Jacket, Red and Blue, Yellow and Green, Black and White, Purple and Pink*)
10. **Unit 10**: *Family & Dream Jobs* (Keluarga & Cita-cita Pekerjaan: *Father, Mother, Brother, Sister, Grandfather, Grandmother, Teacher, Doctor, Police officer, Pilot*)

## 📝 Bank Soal Pintar: 100 Soal Per Unit (Total 1.000 Soal Lengkap):

Untuk membantu siswa **mengerti lebih cepat, tidak bosan, dan memahami materi secara mendalam**, sistem kuis kini dilengkapi dengan bank soal raksasa: **100 Soal di Setiap Unit** (Total 1.000 Soal di 10 Unit):

1. **Pilihan Jumlah Soal Fleksibel**:
   - ⚡ **Kuis Kilat**: 10 Soal Acak Cepat dari unit materi.
   - 🌟 **Tantangan 25**: 25 Soal Modul pilihan.
   - 🏅 **Latihan Ujian**: 50 Soal Intensif persiapan ulangan.
   - 💯 **Maraton 100 Soal**: Menjawab SELURUH 100 Soal Lengkap di unit tersebut!
   - 🏆 **Grand Challenge**: 25 Soal Campuran dari SELURUH 10 Unit materi.

2. **10 Model Variasi Tipe Soal (Super Variatif)**:
   - **Tipe 1 (Arti Kosakata En ➔ Id)**: Menentukan arti kata bahasa Inggris dalam konteks kalimat.
   - **Tipe 2 (Terjemahan Istilah Id ➔ En)**: Menentukan istilah bahasa Inggris yang tepat dari bahasa Indonesia.
   - **Tipe 3 (Lengkapi Kalimat / Contextual Fill-in)**: Melengkapi kalimat rumpang beserta arti kalimatnya.
   - **Tipe 4 (Tantangan Ejaan / Spelling Bee)**: Menentukan urutan ejaan huruf yang benar.
   - **Tipe 5 (Tebak Visual & Ikon Gambar)**: Menjodohkan gambar nyata dan ikon emoji dengan kosakata.
   - **Tipe 6 (Percakapan Sehari-hari / Dialogue)**: Melengkapi dialog tanya-jawab singkat kontekstual.
   - **Tipe 7 (Benar atau Salah / True or False)**: Menilai kebenaran pernyataan logika materi bahasa Inggris.
   - **Tipe 8 (Pasangan Kata & Karakteristik)**: Menghubungkan fungsi alat, pasangan kata, atau matematika dasar.
   - **Tipe 9 (Tata Bahasa / Grammar Dasar SD)**: Latihan to be (am/is/are), kata sandang (a/an), dan preposisi.
   - **Tipe 10 (Situasi Nyata & Logika Kasus)**: Menerapkan bahasa Inggris pada situasi nyata sehari-hari siswa.

3. **Penjelasan Edukatif Instan**:
   - Setiap kali siswa menjawab, sistem langsung menampilkan **kotak penjelasan lengkap** (arti kata, alasan jawaban benar, ejaan, dan tombol audio) sehingga siswa langsung paham sebelum lanjut ke nomor berikutnya.

## 🖥️ Deploy di Server Sekolah / Lab (Proxmox VE LXC):

Aplikasi ini sangat ringan dan siap di-deploy pada container **LXC Proxmox (Debian 12 / Ubuntu)** menggunakan Nginx Web Server.

Panduan lengkap instalasi bertahap dan cara update dapat dibaca di berkas:
👉 **[PANDUAN_PROXMOX_LXC.md](PANDUAN_PROXMOX_LXC.md)**

### Quick Setup di Terminal LXC:
```bash
apt update && apt install -y git
git config --global --add safe.directory /var/www/bahasa-inggris
git clone https://github.com/kajurtkjsmkbp-hub/bahasa-inggris.git /var/www/bahasa-inggris
cd /var/www/bahasa-inggris
bash scripts/setup-lxc.sh
```

### Quick Update di Terminal LXC:
```bash
update-lms
```
*(atau jalankan satu baris perintah manual ini):*
```bash
git config --global --add safe.directory /var/www/bahasa-inggris && cd /var/www/bahasa-inggris && git fetch origin main && git reset --hard origin/main && chown -R www-data:www-data /var/www/bahasa-inggris && systemctl reload nginx
```
